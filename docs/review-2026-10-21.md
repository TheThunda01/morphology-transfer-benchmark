# Maintenance and scientific review — 21 October 2026

This follow-up covered the README, current scientific guides, data dictionary, source and license records, assumptions, generated-report wording, and saved results. The original data, configuration, and result files were retained.

## Findings and changes

The TSV annotation file is now explicitly stored with LF line endings. A normal Windows checkout could previously convert it to CRLF and fail the correct input-hash check before analysis. The fix preserves the recorded bytes; it does not weaken verification. CI now runs tests and reproduction on Ubuntu and Windows.

Newly generated reports, figures and explanatory metadata say **distinct compound groups**, rather than **independent groups**. Connectivity grouping prevents exact identity reuse but does not establish biological or statistical independence. Frozen outputs retain their original labels. The comparator recognizes the one documented legacy metadata sentence while continuing to compare all numerical results and other fields.

The source study reports 1,790 extracted measurements before subsequent processing. The previous comparison with “1,781 source features” was unsupported at that stage and was replaced with wording that distinguishes extraction from this fixed 72-feature panel.

## Dose-source reconciliation

Way et al.'s **Selection of compounds for testing** section lists the usual six doses as 0.04–10 μM. Its Methods distinguish 48-hour Cell Painting from 24-hour L1000 measurements. The pinned profile pipeline uses the matching numeric dose grid and passes `Metadata_mmoles_per_liter` directly to a nearest-category function without conversion. The selected records contain numeric 10 and category 6.

This is consistent with an intended 10 μM condition and a misleading metadata name. It does not independently verify dispensing for each well. The expanded [provenance note](data-provenance.md#what-was-selected) records the exact code path and the remaining limit. Raw values are unchanged; a cross-study absolute-dose comparison still needs the original experimental metadata. Relevant paper sections and both source functions were inspected; supplementary materials were not comprehensively reviewed.
