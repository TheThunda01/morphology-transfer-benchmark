# References

The papers below support the biological rationale and its limitations. The software documentation establishes where the data came from; it is not independent evidence of biological validity. Sources were inspected on 20 October 2026; the [search log](search-log.json) records the search and access limits.

[DOI: 10.1016/j.cels.2022.10.001](https://doi.org/10.1016/j.cels.2022.10.001) · [PubMed 36395727](https://pubmed.ncbi.nlm.nih.gov/36395727/) · [PMC full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC10246468/). ## Practical comparison with the upstream tools

The official LINCS workflow [4] computes image-derived features, aggregates cells into well profiles, and provides normalized and feature-selected levels. This repository starts at its annotated Level 3 medians, selects a small fixed feature panel, and fits subsequent transforms with explicit control and training boundaries. It is a compact audit and teaching benchmark, not a replacement for upstream CellProfiler analysis or a reproduction of the paper's full feature set. No upstream source code was copied. NumPy and scikit-learn provide the local numerical and model implementations; their availability is not evidence that the biological interpretation is correct.
